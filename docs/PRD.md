# Onda 听力训练产品需求

## 目标与范围

服务 A1–B2 第二语言学习者，首发意大利语。保留 Online Italian Club 的原声、题目、课文与来源。工作台帮助学习者从听懂某一篇，走到听懂陌生说话者的新材料。每个任务分别观察语音解码、实时处理、篇章理解与迁移，跨任务观察延迟保持与信心校准。这些是行为观察维度；任何稳定的能力等级都需要足够样本和测量验证。

当前本地版有独立工作台、A1 课程集、原声播放器、可选展开的原文、首听大意草稿、A–B 精听、听写、可修改的自评标签、随文问答和文字短语复习。现已加入每日预算计划、三道可判分的首听理解题、逐词听写对照及个人难段的到期音频复习；其余课程记录首听大意与信心。正式诊断、覆盖全库的核验题目、多说话者训练和留出测评属于后续交付。

## 学习者路径

1. 设置目标语言、CEFR、每日 15/30/45/60 分钟或自定义时长、目标及主题。已有学习者可直接进入工作台。
2. 用约 10–15 分钟完成初诊。A 用短句候选项测试音素、词界与弱读；B 用 5–15 秒无字幕句子测试语义；C 用 1–2 分钟对话测试时间、因果与意图；D 使用留出的说话者测试迁移。
3. 报告按任务展示答对数、样本数、错误实例和可能的训练方向。可同时推荐多个方向。数据不足时明确标注。
4. 从每日计划进入训练，保留初答、反馈与修正。难段进入复习，到期先听再答。每周用留出材料检验迁移。

## 五种训练方法

| 模块 | 学习操作与反馈 | 验收观察 |
|---|---|---|
| 精听与错误诊断 | 无字幕听 30–90 秒并答大意；复听时标记难段，局部听写，展开参考句对照遗漏与替换，自选错误标签，循环后整段盲听。 | 首答和核对后答案分别保留；能保存难段并从同一录音准确重播。 |
| 高变异语音感知 | 用已授权真实录音做音素分类、最小对立体及句内识别，例如 pala/palla。选择后揭示正确词及长短辅音差别，换说话者再听。 | 能按说话者和音类统计；用未见录音单独测泛化。 |
| 元认知训练 | 读主题作预测，整段盲听，提交理解与信心，复听关键证据并修正，最后对照原文反思。 | 同屏回顾预测、初答、信心、修正及对应的语音证据。 |
| 连续泛听 | 按程度、时长和主题选择对话、播客或访谈，连续播放后回答大意题，再按需看关键词、字幕并自评难度。 | 播放中无需频繁答题；调整难度参考多次表现。 |
| 间隔听觉复习 | 卡片正面播放收藏片段，尝试识别词组或意义，提交后揭示文本，再安排下次复习。 | 分别记录可核对的识别结果、主观难度和实际间隔。 |

错误标签支持音素混淆、词汇切分、词汇提取、句法处理、语义整合、注意或记忆。归因是可修改的假设。AI 可以解释差异，参考文本存疑时允许标记待核对。

## 每日计划与指标

60 分钟起始模板为精听 20、辨音 15、泛听 20、复习 5 分钟。其他预算缩放并向用户解释取舍。反复音类错误增加辨音；识词好但理解差增加句义题；短句好而长对话弱增加篇章任务；旧材料好而新材料弱增加陌生语料；延迟识别弱则缩短复习间隔。任务替换须在每日预算内完成。具体比例、间隔和阈值均为可调产品配置。

核心指标为首次遇到无字幕新录音的理解正确率、标准化识别准确率、延迟保持率、留出说话者的迁移表现。每个比例显示分子、分母与条件。另报信心与正确率的匹配、字幕使用、复听、任务难度与频次。学习时长仅作过程记录。

## 交付顺序与验证

- **第一阶段**完成设置和计划、播放器、有校验时间戳的句级字幕、首听理解题、听写对照与错误统计，用人工核对的意大利语材料跑通精听。
- **第二阶段**接入多录音辨音、到期音频复习、每周陌生材料测评、分析与规则推荐，跑通训练到迁移测评的闭环。
- **第三阶段**加入经审核的 AI 题目、错误解释、多说话者泛化训练、个性化难度估计及长期趋势。

整体验收覆盖初诊、可解释推荐、无字幕首答、难段定位、文本核对、到期音频提取、多说话者辨音、连续泛听、陌生材料周期测评及分条件报告。研究评估使用未训练的等值前后测，比较自适应组与等时长同素材固定计划组，控制程度、材料难度和既有经验；报告新材料理解变化、辨音、迁移、保持、主观负担、可用性与不确定性。
